# Shelf for Windows — 第1段階

Windows 11 / C# / .NET 8 / WPF。既存のmacOSコードには依存しません。

## 現在の機能

- プライマリモニターの作業領域の左端に、最前面の棚を表示
- エクスプローラーから複数の実在するファイルを登録（重複パスは除外）
- ファイル名とフルパスを一覧表示
- 一覧の行から他アプリへコピーとしてドラッグアウト
- ドラッグアウト成功・中断のいずれでも棚に保持
- 選択項目はボタンで明示的に一覧から除去

ファイルの内容には書き込みません。登録はパス参照だけです。ドラッグでは
`FileDrop`形式と`Copy`操作のみを公開し、`Move`は公開しません。
ドロップ先アプリがファイルをどう扱うかまでは制御できません。

今回はメモリ内だけの一覧です。終了すると登録内容は失われます。
フォルダー、テキスト・画像・URLの個別取り込み、折り畳み、モニター選択、
トレイ、ホットキー、永続化は未実装です。通常の閉じるボタンで終了します。
AppDataへの保存処理もまだありません。後続の保存先は `%LOCALAPPDATA%\Shelf` とします。

`IDragDataProvider`でドラッグデータ生成を分離しています。将来はこの境界を拡張し、
生成ファイルに加えてUnicodeテキストやURL形式を公開できます。
