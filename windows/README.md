# Shelf for Windows — v0.2 / 第2段階

Windows 11 x64 / C# / .NET 8 / WPF。軽量版は **.NET 8 Desktop Runtime x64** が必要です。

## 使える機能

- ファイルのドロップ登録、複数ファイルの一覧、コピーとしてのドラッグアウト
- ドラッグアウト成功・キャンセル後も棚に保持。除去はボタン操作だけ
- 右上の `‹` で折り畳み、帯を左クリックして展開（ホバー展開なし）
- 折り畳んだ帯へのファイルドロップ、登録件数表示
- 選択モニターの作業領域左端に最前面表示（タスクバーの領域を避ける）
- モニター選択欄と帯の右クリックメニューから配置先を切り替え
- モニター表示: DISPLAY識別子、メイン画面、解像度、左上座標（物理px）
- モニター切断・構成変更時の再列挙、配置先消失時のメイン画面への復帰
- 一覧・配置先・折り畳み状態の保存と復元

モニター数を3台に固定していません。接続画面を列挙し、3台構成を想定して実装しています。
Windows 11実機での第2段階の操作、混在DPI、3画面での配置・切断復帰は未検証です。

## データとファイル保護

元ファイルの内容を変更・コピー・移動・削除せず、パス参照だけを保存します。
ドラッグは`FileDrop`形式と`Copy`操作だけを公開します。受け取り先アプリの処理は制御できません。

保存先は `%LOCALAPPDATA%\Shelf\items.json` と `settings.json`。
登録・一覧からの除去・設定変更時に保存します。2回目以降の保存では直前のデータを`.bak`に保持し、
同じフォルダーの一時ファイルから置き換えます。アプリが削除するのは自身が作成した保存用一時ファイルだけです。
一覧除去によって元ファイルを削除することはありません。

元ファイルが見つからなくても参照を保持し、一覧やドラッグ開始時に知らせます。
保存失敗は棚に警告、帯には`!`を表示します。保存できない変更がある状態で終了する場合は確認します。
壊れた/未対応のJSONは上書きせず保護し、そのファイルへの保存を停止します。
有効なバックアップがあれば表示します。復旧方法はWindows-Setup.mdを参照してください。
一覧・設定は別ファイルなので、片方の保存失敗で他方まで停止しません。
二重起動を防止します。v0.1との同時起動は避けてください。
