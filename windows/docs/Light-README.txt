Shelf Windows 11 v0.2 軽量版（x64）

【起動】
1. 第1段階のShelfが動いている場合は終了してください。
2. https://dotnet.microsoft.com/download/dotnet/8.0 から
   「.NET Desktop Runtime 8.0」のWindows x64版をインストールしてください。
   v0.1軽量版が起動していれば、通常はすでに導入済みです。
3. ZIPを右クリックして「すべて展開」を選び、新しいフォルダーへ展開します。
4. 展開先のShelf.Windows.exeをダブルクリックします。
   DLL・JSONも同じフォルダーに置いてください。管理者として起動しないでください。

【操作】
- ファイルを棚へドロップして登録。行を外へドラッグするとコピーとして渡します。
- ドラッグアウト後も棚の項目は残ります。
- 右上の ‹ で折り畳み、帯を左クリックして展開します。ホバー展開はしません。
- 帯にもファイルを直接ドロップできます。
- モニター選択欄にDISPLAY識別子・解像度・左上座標を表示します。
  座標は仮想デスクトップの物理pxで、左/上の画面は負の値になります。
  DISPLAY番号はWindowsのデバイス識別子で、設定画面の「識別」番号と同じとは限りません。
- 帯を右クリックすると、展開・モニター選択・終了ができます。
- 展開時の × または右クリックメニューで終了します。

【保存】
%LOCALAPPDATA%\Shelf\items.json と settings.json に参照と設定を保存します。
元ファイルは変更・移動・削除しません。一覧からの除去も元ファイルには影響しません。
登録内容、配置先、折り畳み状態は次の起動で復元します。
見つからないファイルの参照も残します。
帯の ! は保存警告です。左クリックで展開して内容を確認してください。

【制限とテスト】
第2段階のWindows実機動作は未検証です。同梱のWindows-Test-Checklist.mdで確認してください。
第1段階の実機成功結果は、この新バージョンの動作確認を代替しません。
未署名の試作版です。警告が出た場合は入手元を確認し、保護機能を無効化しないでください。
