# Windows 11実機チェックリスト

すべて未実施です。実機でビルド・起動してから記録してください。
最初に新しいテスト用フォルダーとファイルを用意し、同名ファイルのない別フォルダーをコピー先にします。

- [ ] Releaseビルドが成功し、標準ユーザーで起動する。
- [ ] プライマリモニターの作業領域左端に表示され、他の通常ウィンドウより前に残る。
- [ ] ファイル1個、複数個、日本語・空白・長い名前のファイルを登録できる。
- [ ] 同じパスは重複登録されない。別フォルダーの同名ファイルは両方登録される。
- [ ] フォルダーやプレーンテキストのドロップでは登録されない。
- [ ] 名前やパスの表示上からドラッグできる。空白部分からは開始しない。
- [ ] 別フォルダーへのドロップでコピーが作られ、棚の項目が残る。
- [ ] Escapeでキャンセルした場合も棚の項目が残る。
- [ ] Shiftを押しても元ファイルが移動しない（拒否になる場合は許容）。
- [ ] 棚自身に戻しても重複や除去が起きない。
- [ ] ボタンで取り除いても元ファイルが残り、内容が変わらない。
- [ ] 登録後に元ファイルを別途退避した場合、ドラッグ時にエラー表示して項目を残す。
- [ ] 終了・再起動で一覧が空になる。元ファイルは変わらない。
- [ ] 公開フォルダー全体をSDKのないWindows 11端末にコピーして起動できる。

元ファイルの確認には、前後で次の結果を比較できます。

```powershell
Get-FileHash "C:\テスト用\sample.txt" -Algorithm SHA256
Get-Item "C:\テスト用\sample.txt" | Select-Object FullName, Length, LastWriteTimeUtc
```

将来の3画面対応は今回の合格条件に含みません。最前面表示は排他的フルスクリーン、
UACなどのセキュアデスクトップでは保証しません。受け取り先アプリごとの挙動も実機確認が必要です。
