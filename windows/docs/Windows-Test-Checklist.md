# Windows 11実機チェックリスト — v0.2

第2段階の実機テストはすべて未実施です。第1段階の成功結果とは区別して記録してください。
テスト用の元ファイルと、同名ファイルがないコピー先フォルダーを用意します。
保存データが既にある場合は、Shelfを終了して `%LOCALAPPDATA%\Shelf` を別の場所へコピーして保管してください。

## 1. 第1段階の回帰確認

- [ ] 標準ユーザーで起動。複数ファイル、日本語・空白・長い名前のファイルを登録できる。
- [ ] 同じパスは重複せず、別フォルダーの同名ファイルは両方登録できる。
- [ ] 行から別フォルダーへドラッグしてコピーできる。成功後も棚の項目が残る。
- [ ] Escapeでドラッグをキャンセルしても項目が残る。
- [ ] Shiftを押しても元ファイルが移動しない（受け取り拒否は許容）。
- [ ] 自分の棚へ戻しても重複・自動除去しない。
- [ ] 明示的に一覧から除去しても元ファイルが変わらない。
- [ ] テキストやフォルダーなど、対象外のドロップは登録しない。

## 2. 折り畳み

- [ ] `‹`で帯になり、件数が表示される。左クリックで展開できる。
- [ ] マウスを乗せるだけでは展開しない。
- [ ] 帯にファイル1個・複数個をドロップし、帯のまま件数が増える。
- [ ] 展開すると、以前の項目と帯へ追加した項目が両方残っている。
- [ ] 帯の右クリックで展開、モニター選択、終了ができる。

## 3. 3画面と異なる表示倍率

各画面の解像度・倍率・配置、選択時の結果を記録してください。
例: DISPLAY1=1920×1080/100%/(0,0)、DISPLAY2=2560×1440/125%/左側、DISPLAY3=3840×2160/150%/上側。
`DISPLAYn`はデバイス識別子で、Windowsの「識別」番号とは一致しない場合があります。

- [ ] 3画面それぞれの識別子・解像度・左上座標・メイン画面表示で配置先を判別できる。
- [ ] 展開時の選択欄から3画面を順番に選び、その画面の作業領域左端に表示される。
- [ ] 折り畳んだ状態でも右クリックで3画面を切り替えられる。
- [ ] 各画面で折り畳み・展開・ドロップ・ドラッグアウトができる。
- [ ] 100%/125%/150%（可能なら200%）混在で、文字と操作が極端に小さく/大きくならず、棚が画面内に収まる。
- [ ] 左側・上側の負の座標のモニターでも正しい画面へ移る。
- [ ] タスクバーの位置・解像度・倍率を変更しても配置を再調整する。
- [ ] 配置先のモニターを切断すると、メイン画面へ戻って操作できる。
- [ ] 再接続後、一覧から元の画面を選び直せる。スリープ復帰後も操作できる。
- [ ] 通常の他アプリより前に残る。排他的フルスクリーン・UAC画面は対象外。

## 4. 保存と復元

- [ ] ファイルを登録すると `%LOCALAPPDATA%\Shelf\items.json` が作成される。
- [ ] 除去操作・再起動後に、その除去が反映される。元ファイルは残る。
- [ ] 複数ファイルを登録して終了・再起動すると、同じ順序で復元される。
- [ ] 第2/第3画面を選んで終了・再起動すると、配置先を復元する。
- [ ] 帯にして終了・再起動すると、帯と件数を復元し、左クリックで展開できる。
- [ ] 保存済みの配置先がない状態で起動すると、メイン画面へ復帰する。
- [ ] 登録済みファイルを別途退避して再起動しても参照が消えず、「見つかりません」と表示する。
- [ ] 二重起動で新たな棚を作らず、既に起動している旨を表示する。

任意の異常系: 必ずアプリ終了とAppDataのバックアップを行い、テスト用データで試してください。

- [ ] `items.json`を不正なJSONにして起動すると警告を表示し、元データを上書きしない。
- [ ] 有効な`.bak`がある場合はバックアップを表示するが、問題のJSONへの保存は停止する。
- [ ] 帯で保存警告の`!`が見え、展開すると説明を読める。
- [ ] 未保存の変更がある場合の終了確認で「いいえ」を選ぶと棚に戻る。
- [ ] Windows-Setup.mdの復旧手順で保存を再開できる。

## 元ファイルの前後比較

登録・コピー・一覧除去の前後に、同じ元ファイルに対して実行して比較します。

```powershell
Get-FileHash "C:\テスト用\sample.txt" -Algorithm SHA256
Get-Item "C:\テスト用\sample.txt" | Select-Object FullName, Length, LastWriteTimeUtc
```
